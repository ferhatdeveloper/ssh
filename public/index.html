🧙 Tık-Tıkla Kurulum Sihirbazı

Sihirbaz Terminal sekmesinin sağ üstündeki "🧙 WireGuard Sihirbazı" butonuyla açılır. SSH bağlıyken her adımı tek tek tıklayarak ilerleyebilirsiniz:

  1. Ortam algılama — OS, paket yöneticisi, sudo yetkisi
  2. WireGuard Kurulumu — paket + anahtar + wg0.conf + IP yönlendirme + servis
  3. İlk Peer Ekle — telefon için .conf + QR kod
  4. WGDashboard Kur — web panel (peer yönetimi için)
